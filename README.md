Panel Vice is a multi-panel cover art studio that turns your own photos and a caption into striking GTA-style poster covers, entirely offline in the browser. Pick from five layouts (Full Bleed, Quad Grid, Hero & Three, Nine Panel with a halftone title block, and Snapshot Trio), frame each panel by dragging and zooming, apply one of five colour grades (Vice Sunset, Neon Nights, Teal Heat, Flamingo Candy, Noir Ink) with optional film grain and vignette, and style the lettering with sunset-gradient Anton capitals, a neon Pacifico script subtitle, heat stars and a ribbon badge. Export a finished cover as a PNG in 1080×1080, 1080×1350, 1920×1080 or 1080×1920 in one click — photos are read locally and never uploaded, and all artwork, lettering and fonts (Anton and Pacifico, SIL Open Font License) are original or openly licensed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve the `app/` folder with any static file server.
